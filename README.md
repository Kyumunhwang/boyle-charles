# ⚛️ 중학교 과학 디지털 탐구실 - 보일의 법칙 & 샤를의 법칙

중학교 과학 교과서 속 **보일의 법칙(Boyle's Law)**과 **샤를의 법칙(Charles's Law)**의 탐구 실험([활동하기])과 입자 모형([해보기])을 그대로 재현하여, 학생들이 직접 시뮬레이션을 조작하고 그 결과값을 스마트 탐구 노트에 기록·정리할 수 있는 웹 기반 과학 교육 플랫폼입니다.

---

## 🌟 주요 기능 및 교과서 연계

### 1. 🧪 보일의 법칙 (기체의 압력과 부피 관계)
* **[활동하기] 디지털 압력 센서를 이용한 그래프 그리기**
  - 20 mL 플라스틱 주사기 피스톤 조절 (10 ~ 20 mL)
  - 디지털 압력 센서 및 스마트 기기 디스플레이 실시간 연동 ($1.00 \to 2.00\text{ atm}$)
  - 측정값 원클릭 기록 및 실시간 반비례 곡선($P \times V = k$) 그래프 생성
* **[해보기] 기체의 압력에 따른 부피 변화를 입자 모형으로 해석하기**
  - (가) 60 mL vs (나) 30 mL 주사기 피스톤 누르기 전/후 분할 비교
  - 입자의 크기·개수(10개)·운동 빠르기(화살표 길이)는 일정하게 유지
  - 좁아진 공간에 따른 단위 시간당 벽면 충돌 횟수 2배 증가 시각화

### 2. 🔥 샤를의 법칙 (기체의 온도와 부피 관계)
* **[활동하기] 기체의 온도와 부피 관계**
  - 500 mL 비커 속 20 mL 유리병과 5 mL 눈금 피펫
  - 수온 조절 (10 ~ 60 ℃)에 따른 피펫 속 붉은 색소 방울의 실시간 이동
  - **피펫 눈금 정밀 확대경(Magnifier View)**으로 0.1 mL 단위 정밀 관측
  - 온도-부피 선형 비례 직선 그래프 실시간 생성
* **[해보기] 기체의 온도에 따른 부피 변화를 입자 모형으로 해석하기**
  - (가) 60℃ 온수(고온) vs (나) 15℃ 냉수(저온) 비교
  - 온도 상승에 따른 기체 입자의 속도 벡터(화살표 길이) 증가 및 벽면 충돌 세기 강화 시각화

### 3. 📝 스마트 탐구 노트(노트테이킹) & 평가 지원
* **실시간 자동 저장 (`LocalStorage`)**: 새로고침하거나 브라우저를 닫아도 기록 데이터 안전 보존
* **교과서 질문 & 서술형 작성**: 핵심 과학 용어 칩 제공 및 학생 자율 서술
* **스스로 평가하기 퀴즈**: 즉각적인 정답 피드백 제공
* **교사용 모범 답안 / 힌트 토글**: 수업 중 공개 또는 자가 점검용
* **A4 활동지 인쇄 및 PDF 저장**: 수행평가 제출용 서식 및 선생님 평가 등급(상/중/하) 확인란 포함

## 🚀 실행 및 배포 방법

### 1. 웹 브라우저에서 바로 실행 (오프라인 가능)
별도의 서버나 인터넷 설치 없이 `index.html` 파일을 더블 클릭하면 모든 최신 웹 브라우저(Chrome, Edge, Whale, Safari 등)에서 즉시 실행됩니다.

### 2. Streamlit을 통한 로컬 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

### 3. Streamlit Cloud 웹 배포 방법
1. [Streamlit Community Cloud](https://share.streamlit.io/)에 접속하여 로그인합니다.
2. **`New app`** 버튼을 클릭합니다.
3. Repository: `Kyumunhwang/boyle-charles`
4. Main file path: `app.py`
5. **`Deploy!`** 버튼을 누르면 수 초 내에 전 세계 어디서든 접속 가능한 웹 링크가 생성됩니다.
